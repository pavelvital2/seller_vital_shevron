# Ozon Hashtag Frequency Table

Дата создания: 2026-06-14
Дата последнего обновления частотности: 2026-06-14

## Назначение

Таблица нужна для подбора хештегов Ozon в карточки Vital Shevron.

Частотность в этой таблице собрана из выпадающих подсказок поля `#Хештеги` в редакторе карточки Ozon. Ozon показывает число товаров с хештегом; это не точная частотность поисковых запросов и не показатель спроса.

Рабочий принцип: сначала использовать релевантные запросы, по которым карточка уже видна в выдаче, затем добирать до 30 хештегов по убыванию подтвержденной частотности. Таблицу обновлять не реже одного раза в месяц.

Важно: `#бпла` не использовать, владелец сообщил, что Ozon его не пропускает.

## Поля таблицы

| Поле | Значение |
| --- | --- |
| `seed` | Базовый проверенный запрос |
| `rank_in_dropdown` | Позиция в выпадающей подсказке Ozon |
| `hashtag` | Хештег с `#` |
| `frequency_text` | Частотность как показал Ozon |
| `frequency` | Нормализованное число товаров |
| `relevance` | `yes`, `conditional`, `candidate`, `no`, `blocked` |
| `normalized_from` | `joined`, `underscore`, `manual/current` |
| `frequency_checked_at` | Дата проверки частотности |
| `status/note` | Практическое решение и комментарий |
