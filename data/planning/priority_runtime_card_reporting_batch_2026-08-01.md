# Пакет доработок runtime, карточек и отчетности от 2026-08-01

## Цель

Довести до устойчивого состояния пять уже начатых контуров без операций записи
в Ozon/WB: карточный pipeline, runtime Telegram-бота, ежедневный отчет, dry-run
`Цены и маржа` и восстановление частично выполненных inbox-операций.

## Ограничения

- marketplace write в рамках разработки не выполнять;
- существующие API-first, Job Worker, approval и RunManifest контракты сохранять;
- новые write-маршруты не добавлять без отдельного owner approval;
- сначала тесты и локальные dry-run/smoke-проверки;
- не перезаписывать незавершенные пользовательские изменения в worktree.

## План

1. Карточный pipeline:
   - валидатор Layer 2 до owner review/passport promotion;
   - формальные переходы CardWorkItem и история переходов в Job Store;
   - независимые Ozon/WB media-наборы без неявного общего fallback;
   - поддержка актуальных package-полей;
   - закрытие Layer 2/Layer 3 только после подтвержденного apply -> verify.
2. Runtime бота:
   - единый список file/runtime pending approvals;
   - локальные approve/reject и постановка apply/verify в Job Worker;
   - закрытие использованных approval/plan/RunManifest;
   - блокировка повторного применения подтвержденной операции.
3. Ежедневный отчет:
   - отдельный подтверждаемый источник отмен Ozon;
   - фильтрация отзывов и вопросов по границам отчетного дня;
   - reconciliation и полнота расходов;
   - регрессионные тесты на контрольные даты.
4. `Цены и маржа`:
   - единый dry-run для Ozon/WB;
   - расходы за 15/30 дней;
   - расчет на физическое изделие с учетом pack_qty;
   - минимальная, скидочная и базовая цены;
   - stock/action gates;
   - никаких apply-операций в первой версии.
5. Inbox recovery:
   - стабильные action-id;
   - recovery-план только для неподтвержденного хвоста;
   - защита от повторных ответов и mark-read;
   - автоматическое закрытие нулевого хвоста.

## Критерии готовности

- профильные тесты каждого контура проходят;
- полный test suite проекта проходит либо остаточные ошибки документированы;
- runbook, project map и recommendations index актуализированы;
- marketplace state не изменен;
- сохранено компактное Hermes summary без секретов.

## Статус реализации

На 2026-08-01 функциональные пункты 1-5 реализованы. Marketplace write при
разработке не выполнялся. Осталось завершить общий regression-прогон,
актуализацию постоянных документов, Hermes summary и commit/push ветки.
