# Product Card Designer Tasks

Дата создания: 2026-06-14

## Назначение

Файл фиксирует задачи дизайнеру по фото и инфографике карточек Ozon/WB.

Агент обязан обновлять файл при каждом покарточном аудите, если обнаружены:

- меньше 5 полезных фото на Ozon-карточке;
- нет фото варианта ношения;
- нет фото обратной стороны;
- нет фото комплектации;
- нет сервисной инфографики;
- фото противоречит названию/характеристикам;
- фото плохо показывает форму, размер, текст, цвет или фон.

При ежедневной работе с карточками агент должен проверить этот файл:
закрыть устраненные задачи, обновить статус открытых и добавить новые.

## Статусы

- `open` - задача нужна дизайнеру.
- `in_progress` - задача взята в работу дизайнером/владельцем.
- `ready_for_review` - фото подготовлено, нужно проверить перед загрузкой.
- `closed` - недостаток устранен и карточка проверена.
- `deferred` - отложено по решению владельца.
