# Product Card Designer Tasks

Дата создания: 2026-06-14

## Назначение

Файл фиксирует задачи дизайнеру по фото и инфографике карточек Ozon/WB.

Агент обязан обновлять файл при каждом покарточном аудите, если обнаружены:

- меньше 5 полезных фото на Ozon-карточке;
- меньше 5 полезных фото на WB-карточке, особенно если карточку планируется
  переносить на Ozon;
- нет фото варианта ношения;
- нет информации об обратной стороне или, если информация уже есть в
  инфографике, есть смысл добавить отдельное чистое фото обратной стороны как
  улучшение;
- нет фото комплектации;
- нет сервисной инфографики;
- фото противоречит названию/характеристикам;
- фото плохо показывает форму, размер, текст, цвет или фон.

По каждой карточке в аудите нужно отдельно зафиксировать возможность переноса
фото между маркетплейсами:

- `Ozon -> WB` - можно переносить только после проверки всех фото, полноты
  комплекта и, для ведомственных/форменных товаров, необходимости watermark;
- `WB -> Ozon` - можно переносить только после проверки всех фото, читаемости
  и соответствия требованиям Ozon;
- `transfer blocked` - если фото меньше 5, главное фото сырое или слабое,
  нет размера, липучки/комплектности, варианта ношения, сервисного слайда,
  либо фото не соответствует товару. В этом случае сначала нужна задача
  дизайнеру, а создание карточки на второй площадке с текущими фото не
  применять.

При ежедневной работе с карточками агент должен проверить этот файл:
закрыть устраненные задачи, обновить статус открытых и добавить новые.

## Статусы

- `open` - задача нужна дизайнеру.
- `in_progress` - задача взята в работу дизайнером/владельцем.
- `ready_for_review` - фото подготовлено, нужно проверить перед загрузкой.
- `closed` - недостаток устранен и карточка проверена.
- `deferred` - отложено по решению владельца.
