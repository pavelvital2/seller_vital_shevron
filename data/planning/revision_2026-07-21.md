## Исправлено при ревизии

1. HTML validator был жестко привязан к `/usr/bin/google-chrome`. Теперь путь
   можно задать через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`; при отсутствии
   используется системный Chrome или штатный browser Playwright.
2. Временные `agent_workspaces/` и `output/` исключены из Git. Они содержат
   browser screenshots и рабочие файлы агентов, а не исходный код проекта.
3. Job Worker больше не выводит в Telegram сырой текст ошибки, если он содержит
   token, cookie, password, authorization header, API key или storage state.
   Безопасные ошибки нормализуются и ограничиваются 500 символами.
4. Проверено предположение о датах Ozon returns: код уже передает корректный
   RFC3339-диапазон, поэтому необоснованное изменение не вносилось.
