# Seller SKU Rules

Дата: 2026-06-13.

## Итог

Правило описывает формирование новых артикулов продавца для магазина Vital
Shevron. Оно применяется к новым товарам и к будущему плану унификации
артикулов, но само по себе не является разрешением менять уже существующие
`offer_id` Ozon или `vendorCode` WB.

Изменение существующих артикулов продавца на Ozon/WB остается опасной
операцией и выполняется только через:

```text
read-only -> mapping draft -> owner review -> approved mapping ->
dry-run rename plan -> owner approval -> apply -> verify -> result
```

Источник правила: вложенный файл владельца `префиксы артикулов.txt`, получен
2026-06-13.

## Общий формат

Базовый формат:

```text
<product_prefix>[_<kitN|size_prefix>][_purpose_or_position_prefix][_theme_prefix][_structure_prefix]_<content_prefix><number>
```

Правила записи:

- использовать нижний латинский регистр;
- разделять смысловые блоки символом `_`;
- не использовать пробелы и кириллицу;
- номер писать четырьмя цифрами, например `0001`;
- `text` или `pict` пишется слитно с номером: `text0001`, `pict0001`;
- перед созданием нового префикса, которого нет в этой инструкции, обновить
  этот документ и `data/planning/recommendations_index.md`, если изменение
  влияет на каталог или автоматизацию.

## 1. Тип товара

Обязательный первый блок для всех шевронов и нашивок:

| Префикс | Значение |
| --- | --- |
| `nash` | нашивка |
| `chev` | шеврон |
| `loop` | петлица |

Если в ассортименте появится другая продукция, для нее нужно добавить новый
первый префикс отдельным обновлением правила.

Для петлиц используется отдельный укороченный формат без `text/pict`, потому
что это не шеврон и не нашивка:

```text
loop_<structure>_<number>
```

Пример:

```text
loop_fsin_0001
```

## 2. Комплектность, размер и назначение

Следующие блоки добавляются после типа товара, если применимы. Порядок
определяется влиянием на цену и группировку товара:

1. комплектность или дорогой размерный тип;
2. назначение / место ношения;
3. тематика, если она важна для группы товаров;
4. принадлежность к структуре.

Комплектность влияет на цену сильнее, чем подтип позывного, поэтому `kitN`
ставится раньше `pz`. Наспинный шеврон примерно в 3 раза больше обычного
шеврона и дороже, поэтому `back` считается отдельным размерным/ценовым
признаком. Отдельных комплектов только из наспинных шевронов сейчас нет.

| Префикс | Значение |
| --- | --- |
| `kitN` | комплект из `N` штук: `kit2`, `kit3`, `kit4`, `kit5` и т.д. |
| `back` | на спину / наспинный шеврон |
| `pz` | позывной |
| `ng` | нагрудный |
| `nr` | нарукавный |
| `kp` | на кепку |

Если позывной продается комплектом, использовать связку:

```text
kitN_pz
```

Пример:

```text
chev_kit2_pz_text0001
```

Позывные не получают тематический префикс `raz`. `pz` уже является отдельной
категорией товара, поэтому одиночные нагрудные позывные формируются так:

```text
chev_pz_ng_text0001
```

Нельзя формировать `chev_pz_ng_raz_text0001`.

## 3. Тематика

Если у товара есть явно выраженная тематика, которая влияет на группировку и
поиск, добавить тематический префикс после назначения / места ношения и перед
структурой или содержанием.

| Префикс | Значение |
| --- | --- |
| `prikol` | прикол / юмористическая тематика |
| `svo` | тематика СВО |
| `bpla` | тематика БПЛА |
| `raz` | разные / прочая тематика без отдельной тематической группы |
| `sht` | Шторм / штурмовая тематика |
| `voisk` | войсковые / рода войск |
| `gv` | группировка войск |
| `form` | форменные / служебные надписи без структуры |
| `fan` | фанатская тематика |
| `berserk` | Берсерк |

Уточнение владельца от 2026-06-22: `ВДВ` / воздушно-десантные войска
относятся к войсковой тематике `voisk`. Если в названии одновременно есть
`СВО` и `ВДВ`, выбирать `voisk`, а не `svo`.

Пример:

```text
chev_nr_prikol_text0001
chev_nr_raz_pict0001
chev_nr_sht_pict0001
chev_nr_voisk_pict0001
chev_nr_gv_pict0001
chev_ng_form_text0001
chev_back_form_text0001
chev_kp_prikol_pict0001
chev_kp_svo_text0001
chev_nr_bpla_pict0001
chev_nr_fan_pict0001
chev_nr_berserk_pict0001
```

## 4. Принадлежность к структуре

Если у товара есть принадлежность к структуре, добавить соответствующий
префикс. Если принадлежности нет, блок пропустить.

| Префикс | Значение |
| --- | --- |
| `mvd` | МВД |
| `fsin` | ФСИН |
| `rg` | Росгвардия |
| `fso` | ФСО |
| `fsb` | ФСБ |
| `fssp` | ФССП |
| `chvk` | ЧВК |
| `oborg` | общественные организации |

Нагрудные и спинные варианты также должны иметь префикс структуры, если
принадлежность есть.

Пример:

```text
chev_back_mvd_text0001
```

## 5. Содержание

Обязательный блок перед номером:

| Префикс | Значение |
| --- | --- |
| `text` | текст |
| `pict` | картинка / изображение |

`text` использовать для шевронов, где основное содержание - надпись или
текстовая фраза, даже если в исходном `vendorCode` маркетплейса встречается
другой служебный префикс. Пример: "Рыболовные войска" - это текстовый шеврон,
а не `pict`.

`pict` использовать, когда основное содержание - изображение, символ,
эмблема или сюжетная картинка.

Рабочее уточнение владельца от 2026-06-22 для ручного owner-review:

- нарукавные шевроны почти всегда считать `pict`, потому что обычно это
  изображение, символ или эмблема;
- нагрудные шевроны считать `text`, если владелец не указал обратное;
- наспинные шевроны считать `text`;
- шевроны на кепку чаще считать `text`, но если основное содержание - рисунок
  или символ, использовать `pict`;
- окончательное решение по спорным товарам принимает владелец в owner-review,
  а агент должен записывать правку и пересчитывать свободный номер внутри
  нового префикса.

Для catalog mapping силовых структур действует уточнение владельца:
нарукавные шевроны МВД, ФСБ, ФСИН, Росгвардии, ФССП, ФСО и аналогичных
структур считать `pict`, а не `text`, даже если в названии указана структура
словами. Визуально это шеврон с изображением/эмблемой структуры.

Для комплектов шевронов или нашивок текущая рабочая схема сохраняет блок
`text/pict`. До отдельного решения о смене схемы не удалять этот блок из
`internal_sku`; для комплектов силовых структур по умолчанию использовать
`pict`.

## 6. Номер

Номер добавляется после `text` или `pict` без дополнительного `_`.

Формат:

```text
0001
0002
0003
```

До отдельного уточнения владельца рабочее правило такое: номер должен быть
уникален внутри полного набора префиксов, чтобы один и тот же seller SKU не
использовался повторно для разных товаров.

Перед созданием нового артикула нужно проверить:

- нет ли такого seller SKU в Ozon catalog;
- нет ли такого seller SKU в WB catalog;
- нет ли такого seller SKU в `data/catalog/unified/` или будущем планe
  унификации.

## Примеры владельца

```text
nash_kit2_rg_pict0001
chev_pz_kit2_text0001
nash_mvd_pict0001
chev_back_mvd_text0001
```

## Проверка перед использованием

Перед добавлением нового товара:

1. Выбрать `product_prefix`: `nash` или `chev`.
2. Добавить комплектность или дорогой размерный тип: `kitN` или `back`, если
   применимо.
3. Добавить явное назначение / место ношения: `pz`, `ng`, `nr` и т.д., если
   применимо.
4. Добавить тематику: `prikol` и т.д., если она явно выражена и важна для
   группы товара.
5. Добавить структуру: `mvd`, `fsin`, `rg`, `fso`, `fsb`, `fssp`, если
   применимо.
6. Добавить содержание: `text` или `pict`.
7. Выбрать следующий свободный четырехзначный номер.
8. Проверить уникальность в Ozon, WB и внутреннем unified/mapping слое.
9. Для cross-marketplace товара связать новый артикул с mapping/common product
   record.

## Подтвержденные уточнения 2026-06-20

- Внутренние артикулы использовать с `_`.
- Номер `0001` вести внутри полной смысловой группы префиксов.
- Использовать более явный вариант с назначением/местом ношения, если оно
  известно: `pz`, `ng`, `nr`, `kp`, `back` и аналогичные короткие коды.
- Шевроны размером `80*50 мм` относить к месту ношения `kp` - на кепку, а не
  к `nr`.
- Для товаров с тематикой "прикол" добавлять тематический блок `prikol` после
  места ношения: например `chev_nr_prikol_text0001`.
- Тематика "прикол" не определяет место ношения: не относить товар к `kp`
  только из-за `prikol`/`prik` в `vendorCode`; место ношения выбирать по
  размеру, фото, названию или уточнению владельца. Если размер `80*50 мм` -
  `kp`, иначе использовать фактическое место, например `nr`.
- Содержание `text`/`pict` определять по самому шеврону, а не по старому
  marketplace seller SKU. Если основное содержание - фраза или надпись,
  использовать `text`. Пример: "Рыболовные войска" - `text`.
- Для товаров без отдельной тематической группы, которые владелец относит к
  группе "разные", использовать тематический блок `raz`: например
  `chev_nr_raz_pict0001`.
- Для товаров тематики "Шторм" использовать отдельный тематический блок `sht`,
  а не общий `svo`, даже если в названии есть слово СВО: например
  `chev_nr_sht_pict0001`.
- Для товаров тематики "войсковые" / рода войск использовать отдельный
  тематический блок `voisk`, а не общий `svo`, даже если в названии есть слово
  СВО: например `chev_nr_voisk_pict0001`.
- Военная прокуратура при присвоении внутренних артикулов относится к
  войсковой тематике `voisk`, а не к `mvd` и не к общей группе `raz`.
- Военная полиция при присвоении внутренних артикулов относится к войсковой
  тематике `voisk`, а не к `mvd`.
- Для товаров тематики "группировка войск" использовать отдельный
  тематический блок `gv`, а не общий `svo` и не `voisk`, даже если в названии
  есть слово СВО: например `chev_nr_gv_pict0001`.
- Для форменных шевронов со служебными надписями без отдельной структуры
  использовать тематический блок `form`: press/пресса, охрана, кадет,
  security/секьюрити, staff/стафф и аналогичные товары. Примеры:
  `chev_ng_form_text0001`, `chev_back_form_text0001`.
- Если владелец при catalog mapping относит товар к ЧВК, использовать
  структурный блок `chvk`: например `chev_nr_chvk_pict0001`.
- Если владелец относит товар к общественным организациям, использовать
  структурный блок `oborg`: например `chev_nr_oborg_pict0001`.
- Для фанатских шевронов использовать тематический блок `fan`: например
  `chev_nr_fan_pict0001`.
- Для шевронов тематики "Берсерк" использовать отдельный тематический блок
  `berserk`: например `chev_nr_berserk_pict0001`.
- Для шевронов тематики "бригады" использовать отдельный тематический блок
  `brig`, а не общий `raz` или `svo`, если владелец явно относит товар к
  бригадам: например `chev_nr_brig_pict0001`.
- Если название содержит `нашивка`, `нашивки` или `нашивок` без явного слова
  `шеврон`, использовать тип товара `nash`, включая названия вида `Комплект
  нашивок ...`. Комплектность сохранять как `kitN`, например
  `nash_kit2_nr_mvd_pict0001`.
- Для комплектов больше 2 штук не указывать место ношения `nr/ng/kp/back`,
  потому что в комплекте могут быть нагрудные, наспинные и нарукавные шевроны.
  Примеры: `chev_kit4_fssp_pict0001`, `nash_kit4_mvd_pict0001`.
- Для `kit2` место ношения можно указывать, если комплект явно состоит из
  однотипных шевронов одного места ношения, например `chev_kit2_nr_mvd_pict0001`.
- Для `kit2` нарукавных комплектов силовых структур использовать ранее
  принятую форму `chev_kit2_nr_<structure>_pictNNNN`, например
  `chev_kit2_nr_fsin_pict0005`.
- Если комплект `kit2` смешанный, например нагрудный + нарукавный, место
  ношения не указывать; использовать общую структуру или тему, например
  `chev_kit2_voisk_pict0001`.
- Для петлиц использовать тип товара `loop`. Если петлица относится к
  структуре, писать структуру сразу после типа товара и номер через `_`:
  `loop_fsin_0001`. Не относить петлицы к `chev` или `nash`.
- Для товаров тематики СВО добавлять тематический блок `svo` после места
  ношения: например `chev_kp_svo_text0001`.
- Если в товаре явно указана тематика БПЛА, использовать тематический блок
  `bpla`, а не общий `svo`, даже если в названии также есть слово СВО:
  например `chev_nr_bpla_pict0001`.
- При сопоставлении Ozon/WB присваивать товарной сущности единый
  `internal_sku`. Текущие `offer_id` Ozon и `vendorCode` WB пока не менять.
- Будущее переименование seller SKU на маркетплейсах в `internal_sku` -
  отдельная опасная операция через dry-run, approval, apply и verify.

Примеры явной схемы:

```text
chev_pz_ng_text0001
chev_kit2_pz_text0001
chev_nr_mvd_pict0001
chev_ng_mvd_pict0001
chev_back_mvd_text0001
nash_nr_rg_pict0001
chev_nr_pict0001
chev_ng_text0001
chev_nr_prikol_text0001
chev_kp_prikol_text0001
chev_nr_raz_pict0001
chev_nr_sht_pict0001
chev_nr_voisk_pict0001
chev_nr_gv_pict0001
chev_kp_svo_text0001
chev_nr_bpla_pict0001
chev_nr_chvk_pict0001
chev_nr_oborg_pict0001
chev_nr_berserk_pict0001
chev_kit4_fssp_pict0001
nash_kit4_mvd_pict0001
loop_fsin_0001
```
