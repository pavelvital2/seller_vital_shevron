# Ozon API Documentation

Дата создания: 2026-06-28.

## Назначение

Локальный индекс официальной документации Ozon Seller API, используемой в
проекте Vital Shevron.

## Приоритетные разделы

- FBO поставки и заявки на поставку.
- Товары и карточки.
- Цены, скидки и минимальная цена.
- Акции и продвижение.
- Отзывы, вопросы и чаты.
- Финансы и отчеты.
- Остатки и склады.

## Локальные official-схемы

- `openapi/seller_swagger_20260629.json` - официальная Swagger-схема Ozon
  Seller API `2.1`, загружена через CDP/ЛК Vital Shevron 2026-06-29, потому
  что прямой shell-доступ к `docs.ozon.ru` возвращал redirect loop.

## Проверенные endpoint-карточки

- `endpoints/supply_order.md` - заявки, поставки и bundle-состав.
- `endpoints/cluster_list.md` - `/v2/cluster/list`, mapping кластера назначения,
  `macrolocal_cluster_id` и складов размещения.

## Правило обновления

Для каждого используемого endpoint-а должна быть карточка в `endpoints/` с
официальным URL, датой проверки, request/response контрактом и нюансами
безопасного использования.

Если официальный сайт документации недоступен, нужно сохранить это как
ограничение и повторить проверку позже; до этого не заменять документацию
догадками.
