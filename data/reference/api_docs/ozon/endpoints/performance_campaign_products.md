# Ozon Performance API: товары CPC-кампании

Дата проверки: 2026-07-30
Статус: verified
Официальный источник: https://docs.ozon.ru/api/performance/

## Назначение

Чтение товаров кампании, добавление отсутствующих товаров и обновление ставок.

## Методы

- `GET /api/client/campaign/{campaignId}/v2/products` - список товаров.
- `POST /api/client/campaign/{campaignId}/products` - добавить товары.
- `PUT /api/client/campaign/{campaignId}/products` - обновить ставки уже
  добавленных товаров.
- `POST /api/client/campaign/{campaignId}/products/delete` - удалить товары
  из кампании.

## Request

Для `POST` и `PUT` используется объект:

```json
{
  "bids": [
    {
      "sku": "2425632140",
      "bid": "3000000"
    }
  ]
}
```

`sku` обязателен. Для стратегии со средней стоимостью клика можно передать
`bid`; если при добавлении его не передать, Ozon назначит конкурентную ставку.
В одну кампанию можно добавить не больше 500 товаров.

Для удаления используется объект:

```json
{
  "sku": [
    "2409630261",
    "2850099121"
  ]
}
```

## Ограничения и нюансы

- `PUT` нельзя использовать для добавления отсутствующего SKU: это метод
  обновления ставок.
- Для CPC-кампании Ozon требует минимальный недельный бюджет по формуле
  `2 000 рублей × количество SKU` после добавления. Если текущего лимита
  недостаточно, `POST` отклоняет весь пакет без частичного добавления.
- Недельный бюджет задаётся отдельно через
  `PATCH /api/client/campaign/{campaignId}` в микро-рублях. Его изменение
  является отдельным финансовым действием и требует отдельного owner approval.
- Перед `POST` нужно получить свежий список товаров кампании и добавить только
  отсутствующие SKU.
- После `POST` требуется повторный `GET` и проверка членства и ставки каждого
  добавленного SKU.
- Перед удалением нужно зафиксировать точный список SKU. После удаления
  требуется повторный `GET` и проверка отсутствия только этих SKU до любых
  последующих изменений кампании.

## Проверка 2026-07-30

Контракт подтверждён по актуальной Swagger-схеме Performance API `2.0`,
открытой по ссылке `Документация API` из раздела ЛК
`Настройки -> API интеграции -> Performance API`.

Live apply 2026-07-30 подтвердил бюджетное ограничение на кампании `20233460`:
при `395` товарах и лимите `834 000 руб.` безопасная ёмкость составляла
`22` товара. Общий `POST` на `27` SKU был отклонён с требованием
`844 000 руб.`; отдельный `POST` на `22` SKU прошёл, повторный `GET`
подтвердил `417` товаров и ставки `3 руб.`. После отдельного owner approval
`PATCH` изменил недельный лимит `834 000 -> 844 000 руб.`, оставшиеся `5` SKU
добавлены через `POST`. Итоговый delayed verify подтвердил `422` товара в
кампании и `27/27` целевых SKU со ставкой `3 руб.`.

Live apply `ozon_cpc_non_callsign_apply_20260730T111100` подтвердил маршрут
удаления: `17/17` позывных удалены через `/products/delete`, после чего
`11/11` обычных товаров добавлены со ставкой `1 руб.`. Итоговый состав
кампании `422 -> 416`, позывных осталось `0`, недельный бюджет не менялся.
