# WB Price Quarantine

Дата проверки: 2026-07-14.

## Официальные источники

- инструкция ЛК `Карантин цен`, обновлена 18.05.2026:
  `https://seller.wildberries.ru/instructions/ru/by/material/price-quarantine`;
- API `Установить цены и скидки`:
  `https://dev.wildberries.ru/docs/openapi/work-with-products#tag/Ceny-i-skidki/paths/~1api~1v2~1upload~1task/post`;
- API `Получить товары в карантине`:
  `https://dev.wildberries.ru/docs/openapi/work-with-products#tag/Ceny-i-skidki/paths/~1api~1v2~1quarantine~1goods/get`.

## Подтвержденный контракт

Инструкция ЛК является более свежим и более строгим источником для расчета
безопасного шага:

- карантин учитывает итоговую цену после скидок;
- порог по умолчанию - снижение цены на `33,3%`;
- владелец может настроить категорийный порог `33,3-47,5%`;
- снижение цены на `50%` и больше выполняется поэтапно;
- корректную цену в карантине можно подтвердить действием
  `Применить новую цену`;
- пока изменение не подтверждено, товар продается по прежней цене.

Текущий API reference содержит старую формулировку: карантин при новой цене
минимум в `3 раза` ниже старой. На 2026-07-14 фактическое поведение ЛК
соответствует более строгой инструкции: снижение итоговой цены на `35%`
перевело шесть новых карточек в карантин.

## Правило Vital Shevron

- порог карантина в ЛК не повышать автоматически;
- при увеличении скидки снижать итоговую цену не более чем на `33%` за один
  upload;
- старый предел `35 п.п.` скидки оставить дополнительным ограничением;
- для перехода `0% -> 55%` использовать `0% -> 33% -> 55%`;
- каждый apply проверять через upload history и WB Prices API;
- при карантине сначала exact-target read-only preflight, затем отдельное
  owner-approved действие и повторный verify.
