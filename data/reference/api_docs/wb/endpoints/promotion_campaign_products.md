# WB Promotion: состав карточек кампании

Дата live-проверки: 2026-07-30.

Официальная документация:

```text
https://dev.wildberries.ru/openapi/promotion
```

## Endpoint

```text
PATCH https://advert-api.wildberries.ru/adv/v0/auction/nms
```

Метод добавляет и удаляет карточки в кампаниях со статусами `4`, `9`, `11`.
Для добавленной карточки WB сначала устанавливает текущую минимальную ставку.

Проверенный payload:

```json
{
  "nms": [
    {
      "advert_id": 37041670,
      "nms": {
        "add": [656160633],
        "delete": []
      }
    }
  ]
}
```

## Подтвержденное ограничение

Ответ `added` не означает, что карточка уже доступна для немедленного
`PATCH /api/advert/v1/bids`. В apply 2026-07-30 WB сначала вернул добавленную
карточку в свежем campaign-read, но общий bid update ещё получил:

```text
nomenclature ... not found in advert
```

Безопасный порядок:

1. отправить exact add;
2. дождаться, пока карточка стабильно присутствует в
   `GET /api/advert/v2/adverts` с положительной системной ставкой;
3. перед bid update повторно проверить все остальные ставки;
4. отправить exact bid package;
5. через задержку перечитать кампании и проверить каждую ставку;
6. при первом `400` проверить фактическое состояние и не повторять общий
   пакет вслепую.
