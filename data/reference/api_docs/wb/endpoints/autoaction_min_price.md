# WB Autoaction Minimum Price

Дата проверки: 2026-07-29.

## Официальные источники

- справка WB `Как установить минимальную цену и блокировку в автоакциях`,
  обновлена 16.06.2026:
  `https://seller.wildberries.ru/instructions/ru/ru/material/how-to-set-minimal-price-and-block-auto-promotions`;
- справка WB `Акции на Wildberries`:
  `https://seller.wildberries.ru/instructions/ru/ru/material/wb-promo-events`;
- оферта WB, пункт 12.8.6: скидка автоакции не применяется, если после нее
  розничная цена продавца станет ниже установленной минимальной цены.

## Подтвержденная семантика

- минимальная цена и блокировка работают только для автоакций;
- обычные акции они не ограничивают;
- минимальная цена запрещает WB автоматически применить скидку автоакции,
  если итоговая цена продавца станет ниже порога;
- значение, равное плановой цене автоакции, разрешает снижение ровно до
  минимальной цены;
- если текущая цена продавца уже равна плановой цене автоакции или ниже нее,
  товар может участвовать без дополнительного снижения, несмотря на
  минимальную цену или блокировку;
- минимальная цена не повышает уже установленную продавцом цену и не запрещает
  владельцу вручную установить цену ниже порога;
- блокировка запрещает именно автоматическое снижение цены. В XLSX доступны
  сроки `7 дней`, `30 дней` и `бессрочно`;
- ручная команда `Добавить все подходящие` в уже идущей автоакции является
  явным обходом ранее установленных ограничений;
- скидка WB за счет площадки отделена от seller-funded скидки: покупательская
  цена может быть ниже, но выплата продавцу рассчитывается от его розничной
  цены.

## Публичный API

На 2026-07-29 публичный Prices API:

```text
GET /api/v2/list/goods/filter
POST /api/v2/list/goods/filter
POST /api/v2/upload/task
```

не подтверждает чтение или запись минимальной цены/блокировки автоакций.
`upload/task` использовать только для `price` и `discount`.

## Внутренний контур ЛК

Живой фронтенд `discounts-prices-v2-front v4.4.2` использует закрытый контур
ЛК под `discounts-prices.wildberries.ru`. Подтверждены маршруты:

```text
GET  /excel/autodiscounts_lock
POST /template/min/price/autodiscounts
GET  /template/min/price/autodiscounts/result
POST /upload/task/min/price/autodiscounts/excel
POST /disable/all/min/price/autodiscounts
POST /disable/min/price/autodiscounts/nm
```

Это не опубликованные Seller API endpoints. Они требуют сессионные LK-заголовки
и не должны использоваться как штатный write-контур без отдельного
checksummed plan/apply/verify процесса и явного одобрения владельца.

Фронтенд подтверждает поля:

```text
autoDiscountLock.minPrice
autoDiscountLock.locked
autoDiscountLock.endTime
```
