# Wildberries API Documentation

Дата создания: 2026-06-28.

## Назначение

Локальный индекс официальной документации Wildberries API, используемой в
проекте Vital Shevron.

## Приоритетные разделы

- Поставки и приемка.
- Контент карточек.
- Цены и скидки.
- Акции и продвижение.
- Отзывы и вопросы.
- Статистика продаж, заказов, остатков.
- Финансы и отчеты реализации.

## Цены и карантин

- `endpoints/price_quarantine.md` - актуальный порог карантина, расхождение
  инструкции ЛК и API reference, безопасный шаг изменения итоговой цены.
- `endpoints/autoaction_min_price.md` - минимальная цена и блокировка только
  для автоакций, публичный API-контракт, внутренние LK-маршруты и текущий
  read-only snapshot Vital Shevron.

## Финансы

- `endpoints/sales_reports_detailed.md` - детализация отчётов реализации за
  период, cursor `rrdId`, лимит 100000 строк и один запрос в минуту.

## Остатки

- `endpoints/current_warehouse_stocks.md` - текущие остатки WB по `nmId`,
  размерам и складам; замена отключенного `/api/v1/supplier/stocks`.

## Продвижение

- `endpoints/promotion_campaign_products.md` - официальный маршрут добавления
  и удаления карточек в кампаниях, задержка регистрации добавленной карточки
  и обязательный verify перед установкой ставки.

## Правило обновления

Для каждого используемого endpoint-а должна быть карточка в `endpoints/` с
официальным URL, датой проверки, request/response контрактом и нюансами
безопасного использования.

Если официальный сайт документации недоступен, нужно сохранить это как
ограничение и повторить проверку позже; до этого не заменять документацию
догадками.
