# Wildberries API Documentation

Дата создания: 2026-06-28.

## Назначение

Локальный индекс официальной документации Wildberries API, используемой в
проекте Vital Shevron.

## Приоритетные разделы

- Поставки и приемка.
- Контент карточек.
- Цены и скидки.
- Акции и продвижение.
- Отзывы и вопросы.
- Статистика продаж, заказов, остатков.
- Финансы и отчеты реализации.

## Правило обновления

Для каждого используемого endpoint-а должна быть карточка в `endpoints/` с
официальным URL, датой проверки, request/response контрактом и нюансами
безопасного использования.

Если официальный сайт документации недоступен, нужно сохранить это как
ограничение и повторить проверку позже; до этого не заменять документацию
догадками.
