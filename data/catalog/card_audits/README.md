# Card Audits

Слой 2 трехслойной карточной архитектуры Vital Shevron.

Эта папка предназначена для результатов личного аудита карточек агентом по
read-only source data из `data/catalog/content/`.

Здесь должны храниться только результаты проверки агентом:

- какие фото реально просмотрены;
- что изображено на каждом фото;
- текущее состояние Ozon/WB;
- проблемы и риски;
- рекомендации `сейчас -> рекомендую -> почему`;
- задачи дизайнеру;
- группы для будущих пакетных изменений;
- статус owner review.

Generated source packages из `data/catalog/content/card_audit_packages/` не
являются аудитом. Они только собирают исходные данные и должны иметь статус
`pending_agent_review`, пока агент не посмотрел все фото и карточные поля.

Рабочие audit-файлы в этой папке не коммитятся. В git хранятся только этот
README и schema.

См. подробное правило:

```text
data/planning/product_card_data_layers_runbook.md
```
